# Kiran Academy Internship - Task 1 (Java)

## Java - 5 Programs

1. Hello World by YOUR_NAME
2. Calculate Profit or Loss
3. Check whether a number is Odd or Even
4. Check whether age is valid and eligible for voting
5. Check whether two words are Anagrams

## Compile

```bash
javac 01_HelloWorld.java
javac 02_ProfitOrLoss.java
javac 03_OddOrEven.java
javac 04_VotingEligibility.java
javac 05_Anagram.java
```

## Run

```bash
java HelloWorld
java ProfitOrLoss
java OddOrEven
java VotingEligibility
java Anagram
```

Replace `Aditya` in Program 1 with your preferred name if required.
